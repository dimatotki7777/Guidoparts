# AutoParts — сайт в стиле магазина автозапчастей

Это готовый статический прототип: главная, каталог, поиск, категории и корзина-счётчик.

## Бесплатный запуск
1. Создай аккаунт на Cloudflare Pages или GitHub.
2. Загрузи три файла: `index.html`, `style.css`, `script.js`.
3. Опубликуй проект.

Для настоящего магазина нужно добавить базу товаров, авторизацию, реальные фотографии, оплату, заказы и API.
